# scenario-test

## Scenarios

### Performance сценарио

| Хэсэг                  | Тодорхойлолт                                                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Тойм**               | Сагсанд бараа нэмэх үед `/cart/add` endpoint-ийн хариу өгөх хугацаа хэвийн ачааллын үед шаардлагатай түвшинд байх. |
| **Системийн төлөв**    | Систем хэвийн ажиллаж байгаа бөгөөд `/cart/add` endpoint идэвхтэй байна.                                           |
| **Орчны төлөв**        | **20 VU**, нийт **20 хүсэлт/секунд** орчим хэвийн ачаалалтай байна.                                                |
| **Гадаад өдөөлт**      | Хэрэглэгч сагсанд бараа нэмэх үйлдэл хийж `/cart/add` endpoint рүү хүсэлт илгээнэ.                                 |
| **Шаардлагатай хариу** | Систем хүсэлтийг амжилттай боловсруулж, сагсны шинэ төлөвийг буцаана.                                              |
| **Хэмжүүр**            | `/cart/add` endpoint-ийн response time: **p95 ≤ 500 ms**, **p99 ≤ 1000 ms** байна.                                 |

### Reliability сценарио

| Хэсэг                  | Тодорхойлолт                                                                                         |
| ---------------------- | ---------------------------------------------------------------------------------------------------- |
| **Тойм**               | Хэвийн хэрэглээний үед хэрэглэгчийн төлбөрийн үйлдэл амжилтгүй болох давтамжийг хянах.               |
| **Системийн төлөв**    | Систем хэвийн ажиллаж, төлбөрийн үйлчилгээ идэвхтэй байна.                                           |
| **Орчны төлөв**        | Хэвийн хэрэглэгчийн ачаалалтай бөгөөд хэрэглэгчид `/pay` endpoint-ээр төлбөр хийх үйлдэл гүйцэтгэнэ. |
| **Гадаад өдөөлт**      | Хэрэглэгч төлбөр хийх хүсэлтийг `/pay` endpoint рүү илгээнэ.                                         |
| **Шаардлагатай хариу** | Систем төлбөрийн хүсэлтийг боловсруулж, амжилттай эсвэл тодорхой алдааны хариу буцаана.              |
| **Хэмжүүр**            | `/pay` endpoint-ийн **error rate ≤ 1% (p95)**, **error rate ≤ 2% (p99)** байна.                      |

### Availability сценарио

| Хэсэг                  | Тодорхойлолт                                                                                                                            |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **Тойм**               | Сервер гэнэт зогссон үед систем автоматаар дахин сэргэж, үйлчилгээг богино хугацаанд үргэлжлүүлэх.                                      |
| **Системийн төлөв**    | Сервер хэвийн ажиллаж, хэрэглэгчийн хүсэлтүүдийг боловсруулж байна.                                                                     |
| **Орчны төлөв**        | Сервер production орчинд ажиллаж байгаа бөгөөд restart/recovery механизм идэвхтэй байна.                                                |
| **Гадаад өдөөлт**      | **ЭВДРЭЛ:** сервер гэнэт crash болж, үйлчилгээ зогсоно.                                                                                 |
| **Шаардлагатай хариу** | Систем серверийг автоматаар дахин ажиллуулж, үйлчилгээг сэргээн хэрэглэгчийн хүсэлтийг дахин боловсруулах боломжтой болно.              |
| **Хэмжүүр**            | **Availability ≥ 99.9% (p95)**, **≥ 99.99% (p99)**; серверийн **сэргэх хугацаа (RTO) ≤ 60 секунд (p95)**, **≤ 120 секунд (p99)** байна. |
